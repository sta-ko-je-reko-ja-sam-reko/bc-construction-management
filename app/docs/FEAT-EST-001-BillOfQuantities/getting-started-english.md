# FEAT-EST-001 - Bill of Quantities

Create estimates as a Bill of Quantities and push them to a project's budget. Requires the **Estimating** module.

## Steps

1. Search for **Bills of Quantities** and choose **New**.
2. Set the **Project** (or leave blank for a tender) and a default **markup %**.
3. Add **heading** and **position** lines; on each position set **Cost Type**, **quantity**, **unit of measure**, and **unit cost**. The page shows total cost and price (with markup).
4. When the estimate is awarded, set **Status = Awarded** and choose **Create Project Budget** to generate the project's budget planning lines.
