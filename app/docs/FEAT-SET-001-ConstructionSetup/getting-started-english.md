# FEAT-SET-001 - Construction Setup & Foundation

This guide explains how to configure Construction Management after installing the app.

## Prerequisites

- Construction Management is installed.
- You have administrator permissions for Construction Management.

## Steps

1. Search for **Construction Setup** and open it.
2. Assign the **number series** for construction documents.
3. Review the **default cost type** used for new estimate lines.
4. On a **Project** card, turn on **Construction Project** to enable construction features for that project.

## Result

The project is now construction-managed: estimating, cost breakdown and cost-control features appear on the project once their respective modules are installed.
