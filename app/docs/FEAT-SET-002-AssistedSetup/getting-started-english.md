# FEAT-SET-002 - Assisted Setup

Construction Management ships a **guided setup** that turns on the features you bought and prepares them so you can start working.

## Run the guided setup

1. Choose the **search** (Tell Me) icon, enter **Assisted Setup**, and open it — or open the **Construction Manager** Role Center and choose **Set up Construction Management**.
2. In the list, find **Set up Construction Management** and choose it. The **Construction Setup** hub opens, listing the features in the order to set them up. Each row shows a status (*Not Started* / *Completed*).
3. Choose a feature (start with **Foundation**). A short wizard opens. On the first step you'll see a note that **the session may restart at the end**.
4. On the **options** step, choose what you want:
   - **Enable this feature** — turns the feature on (its pages and actions appear).
   - **Create and assign number series** — sets up default document numbering for the feature, if not already set.
   - **Import demo data** — adds sample construction data so you can try the feature immediately.
5. Choose **Finish**. You return to the feature list, where you can set up the next feature.
6. Repeat for each feature you want. When you're done, **close the feature list**. If you turned features on or off, the session **restarts once** (a short countdown), after which the enabled features are ready to use.

> Tip: you can re-run the guided setup any time, and you can always fine-tune a feature later from its own **Setup** page (choose **Detailed Setup** in the hub).

## What "enabled" means

A feature that's enabled shows its pages, actions and Role Center tiles, and accepts data (including through the API / Copilot). A feature left disabled stays hidden and is not writable — turn it on here when you're ready for it.
