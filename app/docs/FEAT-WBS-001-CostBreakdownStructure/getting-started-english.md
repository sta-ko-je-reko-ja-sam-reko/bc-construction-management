# FEAT-WBS-001 - Cost Breakdown Structure

View a construction project's costs broken down across its task hierarchy. Requires the **Cost Control** module.

## Steps

1. Open a construction **Project** and choose **Cost Breakdown**.
2. Structure the project with indented **Project Tasks** (phases → work packages → cost items).
3. Set a **Cost Type** on posting-level tasks; optionally set **% Complete**.
4. Review **Budget / Actual / Variance / % Complete** rolled up the hierarchy.
