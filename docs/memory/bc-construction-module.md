**Polymorphic table-logic pattern (mandatory, LS-Central style, adopted 2026-06-29):** NO business logic in table/tableextension triggers, field OnValidate/OnLookup, or event-subscriber bodies. Each delegates ONE line to a swappable interface impl — `Logic().Trigger_OnInsert(Rec)` / `Logic().Validate_X(Rec,xRec)`. Per entity: interface `CONS I<Entity>` + default codeunit `CONS <Entity> Logic` (implements it) + table holds cached interface var with `Logic()` resolver (defaults to the codeunit) and public `Define()` for test-injection/override. Subscribers (table events AND any MS base-app publisher) delegate likewise. **Subscriber-organization convention (user directive 2026-06-29, in templates `_members/event-subscribers.md`):** all subscribers live in dedicated, logically-grouped **pure-proxy** codeunits — `SingleInstance = true`, ONLY `[EventSubscriber]` procs, NO globals/labels/local procedures; each body is one line forwarding to the default interface impl resolved via the SingleInstance `CONS Service Locator` (50013, Core) reached through a local var. Override behaviour in the locator's Implement…() setter, never by editing the subscription. `CONS Sales Retention Events` is the reference proxy; guards (IsTemporary) pushed into the logic impl. **Subscriber entitlement flags (user directive 2026-06-29):** a base-app subscriber fires for ALL tenant users, so on a per-user-licensed product set `[EventSubscriber(...,SkipOnMissingLicense,SkipOnMissingPermission)]` = `true,true` by default → unentitled users (no module permission set, granted via entitlement) silently skip instead of erroring on standard ops.
